# Layout changes

This draft customizes its upstream layout and included mods. The current changes include:

- A terminal-first layout with on-demand Files and Git panels.
- English interface text, project-type icons, and no agent-count pills in space rows.
- Disabled automatic worktree cleanup; explicit worktree actions remain available.
- Agent visibility, OpenClaw gateway detection and reuse-first launching, and an extended **+** menu.
- Non-force Push to the configured upstream, with accessible result details.
- Codex app-server quota reporting and Claude status-line observations with explicit stale and rate-limit handling.
- The `notification-detail` and `new-menu-plus` mods and optional older-Pi compatibility extension.

See `THIRD-PARTY-NOTICES` for source attribution and licenses. The included files retain substantial upstream-derived code and are not represented as an independent rewrite.
